# Contributing to ASD Detection System

Thank you for your interest in contributing! This project is in active development and all contributions are welcome — whether it's fixing a bug, improving visualisations, or helping build the ML model.

---

## 🛠️ How to Contribute

### 1. Fork the repository
Click the **Fork** button at the top right of this page.

### 2. Clone your fork
```bash
git clone https://github.com/YOUR_USERNAME/asd-detection.git
cd asd-detection
```

### 3. Create a new branch
```bash
git checkout -b feature/your-feature-name
```

Use descriptive branch names like:
- `feature/random-forest-model`
- `fix/missing-value-handling`
- `docs/update-findings`

### 4. Make your changes
- Keep code clean and well-commented
- Follow existing code style
- Test your changes before committing

### 5. Commit and push
```bash
git add .
git commit -m "Add: brief description of your change"
git push origin feature/your-feature-name
```

### 6. Open a Pull Request
Go to the original repo and click **New Pull Request**. Describe what you changed and why.

## ⚠️ Guidelines

- This is a research/educational project — keep all contributions ethical and responsible
- Do not commit raw dataset files (they are gitignored)
- Do not use this project for actual clinical diagnosis
