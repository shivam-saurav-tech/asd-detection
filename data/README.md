# Data

This folder is gitignored to avoid committing raw data files.

## How to get the dataset

Download the ASD Screening dataset from Kaggle:
https://www.kaggle.com/datasets/faizunnabi/autism-screening

Place the CSV file inside `data/raw/` before running any notebooks or scripts.

## Folder structure

```
data/
├── raw/          ← place downloaded CSV here
└── processed/    ← cleaned data saved here after preprocessing
```
